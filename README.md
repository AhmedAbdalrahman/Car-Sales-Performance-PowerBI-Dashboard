# Car Sales Performance Dashboard

Built with Microsoft Power BI

## Overview

This project presents an interactive Power BI dashboard developed to analyze car dealership sales performance. The dashboard provides business insights by tracking revenue, profit, sold units, vehicle conditions, monthly sales trends, and top-performing car models through interactive visualizations.

## Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling

## Dashboard KPIs

- Total Sales (USD)
- Total Profit (USD)
- Total Sold Units

## Key Features

- Interactive KPI dashboard
- Monthly sales trend analysis
- Sales by vehicle model
- Vehicle condition distribution
- Profit analysis
- Sales funnel visualization
- Dynamic business insights
